# BlackKnight v0.1.0 release preparation

2026-10-12. The user requested publishing the accepted theme work with E-Jamz.
Release target: https://github.com/auzieman/BlackKnight-E-Theme. The user
selected public publication, GPLv3 original software and CC BY-SA 4.0 original
artwork. The donor distribution boundary below remains in place.

## Accepted deliverables

Original BlackKnight Storm and Still wallpapers, blue-steel materials, AuzieTek
crest adaptation, native build/remap tools, editable EDC and integration notes.
The accepted final local package was built from `ec07f89` by BKC run
`1e17f03e-a97b-4b43-a027-2375afdf2cfc`; its retained checksums verify. Production
cloud cover, strike and clear/reset were observed. See [final build](final-build.md)
and [protected desktop trial](setup-test.md).

The newer right-cap recipe uses 74px of center metal plus a 30px bevel within
the original 104px control backing. Alpha/dimensions and 4,595 unchanged donor
entries were verified; native visual acceptance remains a separate candidate
check. Include its source and inspection as such, without making it the accepted
binary by default.

## Distribution scope

Prepared wallpaper archives and checksums live under `build/out/releases/`.
They contain the original Storm/Still EDJs, optional terminal palette and
provenance. The full Sci-Fi-derived desktop EDJ remains a local artifact while
upstream notices are established; see [source notices](../NOTICE.md).
This preparation does not change desktop selections or re-run rejected trials.

The focus-opacity experiment is rejected after user-reported disruption and is
not enabled or included in runtime packages. Terminal palette visual acceptance,
sustained performance and the right-cap candidate's final visual review remain
follow-ups. Original artwork/compiler inputs and prior evidence remain traceable.
