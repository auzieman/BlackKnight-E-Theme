# BlackKnight Ice terminal palette

An ice-blue Terminology palette derived from the installed Fir Dark color-scheme structure. Its metadata retains the Terminology developers/mk-fg attribution and BSD-2-Clause license. The colors are recorded in `palette.json`; `BlackKnight Ice.eet.txt` is the editable Eet source and `BlackKnight Ice.eet` the compiled color scheme.

The palette uses a blue-black background, pale ice text and cyan highlights while retaining separate red, green and yellow status colors. The Eet encode/decode round trip passed. It is installed in the user Terminology colorschemes folder as a candidate; existing terminal selections are unchanged. Native palette rendering remains a follow-up test. Select **BlackKnight Ice** in Terminology's color-scheme settings to evaluate it.
