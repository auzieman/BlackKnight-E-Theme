# Source and asset notices

Original BlackKnight wallpaper EDC, landscape, cloud/lightning imagery,
blue-steel material and project tools have provenance records in this repository.
A project-wide original-source/artwork license has not yet been selected.

The desktop reskin preserves the user's installed E20 Sci-Fi theme. The donor
identity and source comparison are in
themes/blackknight/desktop/donor-source-proof.json. No upstream license notice
was found in that local source tree during release preparation. Do not attach
the donor-derived full desktop EDJ to a public release until its upstream
terms and required notices are identified. This does not relabel donor code
or artwork as original BlackKnight work.

Original storm/still wallpapers are separate native EDJs and can be packaged
independently. The AuzieTek crest source and transformation are recorded in
themes/blackknight/desktop/assets/griffin-v3/provenance.json.
